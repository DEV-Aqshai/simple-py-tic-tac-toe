# simple py tic tac toe

A two player tic tac toe game that runs in the terminal. Written in plain Python with no dependencies.

## Requirements

Python 3.

## Run

```
python3 tic_tac_toe.py
```

## How to play

1. Enter both player names.
2. Player 1 is X, Player 2 is O.
3. Type a number from 1 to 9 to claim that slot. Slots are numbered left to right, top to bottom.
4. First player to get three in a row wins. The board and score reset for the next round.
5. Type `q` at the prompt after a round to quit.
