# simple py tic tac toe

A two player tic tac toe game that runs in the terminal. Written in plain Python with no dependencies.

## Requirements

Python 3.

## Run

```
python3 tic_tac_toe.py
```

## How to play

1. Enter both player names.
2. Player 1 is `#`, Player 2 is `@`.
3. Type a number from 1 to 9 to claim that slot. Anything else is rejected and re-asked, and occupied slots are refused. Slots are numbered left to right, top to bottom.
4. First player to get three in a row wins. A full board with no line is a draw.
5. Scores carry across rounds until you quit.
6. Press `q` at the prompt after a round to quit and see the final score.
